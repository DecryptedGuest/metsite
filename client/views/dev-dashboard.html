Patrol & Event Log Import

        

          

            Imports every patrol and event log from the configured channels (even the oldest),
            reusing the live parser and skipping misc messages. Idempotent — safe to run repeatedly; it only adds
            what's missing. Historical logs are written straight in as Approved (no review queue,
            no sheet points). Runs in the background; final counts are written to the Audit Trail.
          

          
          

        

      


      
      

        
IA Cases & Tickets Sync

        

          

            Pulls cases and tickets (pending and resolved) from the live IA database (IA_DATABASE_URL)
            into this dashboard. Idempotent — keyed on case/ticket reference. Requires IA_DATABASE_URL to be set.
          

          
          

        

      


      
      

        

          
Rebuild Cases from Discord

          

            
            
            
          

        

        

          

            Every case approved on the site posted an Administrative Log to Discord, built from
            that case: the officer, each punishment and its duration, the reason, the notes, the reference and
            the date. Discord keeps those forever, so the channel is the durable copy and the database is only
            the convenient one. This walks the channel to its first message and rebuilds.
          

          

            Safe to run again after a database move: identity is the log message, so a second pass updates its
            own work instead of duplicating it, and a case somebody filed on the site is never overwritten by a
            reconstruction. Cases that were never approved posted no log, so they cannot come back.
          


          

            
            
            

              The channel your DISCORD_WEBHOOK_URL posts to. Remembered on this device.
            

          


          

            
            
          

          

        

      


      
      

        

          
Clans Labs XP

          

            
            
          

        

        

          

            Sets everyone's XP from the Clans Labs leaderboard in
            data/clanslabs-xp.txt. Their scale runs to six figures and ours stops at
            100 (Chief Inspector), so every number is capped on the way in.
          

          

            The list names Roblox accounts. Where we can find a Discord id for one, the balance is set
            now; where we cannot, the XP is held against the Roblox account and lands on
            their record the first time they log in or somebody runs /xp on them. A claim
            always takes the higher of the two numbers, so re-running this can never take XP off
            anybody. Names the leaderboard cut short are skipped rather than guessed at: Roblox will
            happily answer a lookup for a fragment like “the” with the real
            account of that name, which belongs to a stranger.
          


          

            
            
          

          
          

             Do the dry run first: it does every lookup and writes nothing.
          

          

        

      

    


    
    

      

        
Roblox Audio
Developer · Upload audio to Roblox and collect the asset IDs

      


      
      

        

          
Roblox Credential

          

        

        


          


          

            
            
          


          
          

            

              Create one in the Creator Dashboard → Credentials → API Keys
              (create.roblox.com/dashboard/credentials). Under Access Permissions add the
              Assets API and tick both Read and Write —
              Read alone looks fine here and then fails on the first upload. An API key cannot log in, cannot read
              your account, and can be deleted on its own.
            

            

              Two things that catch people out: a key expires after 60 days unused even with no
              expiry set, and if you tick “Restrict IP addresses” it must list this server’s address
              or every upload is refused. Testing it below reports both.
            

          


          
          

            

               This is your whole account.
              

                A .ROBLOSECURITY cookie authenticates past two-factor. Anyone who gets it holds your
                account until you invalidate it. It is stored encrypted here and never shown again, but the safer
                option is an API key. To invalidate it at any point, log out of Roblox everywhere or change your password.
              

            

            

              In a browser logged into the account: F12 → Application → Cookies → roblox.com →
              .ROBLOSECURITY, and copy the value whole — including the
              _|WARNING:-DO-NOT-SHARE-THIS...|_ at the front. That part is not a note, it is part of the
              cookie, and trimming it stops it working.
            

          


          

            
            
          


          

            

              
              
              

                Must match whoever owns the game the audio is for.
              

            

            

              
              
              

                Open Cloud will not guess whose account it is — the numeric ID from your profile URL.
              

            

          


          

            
            
            
          

          

        

      


      
      

        
Upload Audio

        

          

            .mp3, .ogg, .wav or .flac — under 20 MB and
            7 minutes each, 50 per batch. Roblox also needs a single track, no more than 48 kHz, and mono or
            stereo up to 5.1 — none of which can be checked here, so those come back as its own error.
            Anything you do not hold the rights to will be taken down, so only upload what you are allowed to.
          

          

          

            An ID coming back is not the same as the audio working.

            Roblox queues every upload for moderation, and uploaded audio is private to whoever uploaded
            it. Ownership has to match: audio uploaded on a personal account will not play in a
            group-owned game — it passes moderation, the ID looks fine here, and then the game throws
            not authorized to access Asset. So set “Audio owned by” to the group that owns the
            game before uploading. Sharing it afterwards is possible but fiddly, and audio cannot be replaced —
            fixing a bad upload spends another slot from the monthly allowance. The Moderation column below says where
            each one stands.
          


          

            
            
Drop audio here, or click to choose

            
Names are taken from the file names, and can be edited below
